# Talent Inspirations 🇺🇸

USA-only career job discovery platform.

## Planned stack
- React + Vite + Tailwind CSS
- Node.js + Express
- MySQL
- Playwright/Cheerio job-source adapters
- GitHub Actions CI/CD
- Hostinger VPS + Nginx + PM2

## Rules
- USA jobs only
- Public jobs limited to the latest 30 days
- Latest jobs first
- Admin-managed career-page sources
- Original employer Apply URL is preserved
